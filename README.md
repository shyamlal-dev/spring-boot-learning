# Spring Boot Learning

This repository contains my Spring Boot learning and hands-on practice projects.

## Student Management System

A full-stack, production-ready application for managing student records.

### Current Features

- Create, retrieve, update, and delete students
- Input validation
- Global exception handling
- Duplicate email validation
- RESTful API design
- MySQL database integration

### Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Frontend (Planned)
